# 智承太极 Web 应用 · 启动说明

智承太极——太极拳数字教学与交互展示系统（全国3D大赛精英联赛参赛项目）的可运行 Web 应用。

## 运行方式

```bash
node server.js
```

然后浏览器访问 http://localhost:8080

> 注意：不能直接双击 `index.html` 打开（需要后端 API 与数据持久化）。
> 若 8080 端口被占用（Aniya Studio 的 agentgo 也用 8080），先停掉占用进程再启动。

## 目录结构

| 文件 | 说明 |
|------|------|
| `server.js` | Node 零依赖后端：静态文件 + REST API + `data.json` 持久化 |
| `index.html` | 前端单文件 SPA（约 4200 行，原生实现） |
| `index.html.bak-20260805` | 升级前的备份 |
| `data.json` | 运行时数据（用户/招式/评分/训练记录） |

## API

- `GET/POST /api/user` — 登录信息（姓名/班级）
- `GET /api/dashboard` — 首页统计（分数/境界/本周进度）
- `GET /api/records` — 训练记录
- `GET /api/forms` — 十六式招式列表
- `POST /api/training` — 完成训练上报评分

## 训练闭环规则

- 每式均分 6.25 分，16 式满分 100
- 不重复加分（已掌握招式再练 +0）、不扣分
- 分数完全由训练驱动，从零累积（无后台自动噪声）
- 6 级境界：未开始 / 入门 / 初学 / 小成 / 大成 / 圆满
- 评分报告页按 `N` 键进入下一式
