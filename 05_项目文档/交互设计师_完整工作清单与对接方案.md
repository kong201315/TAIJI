# 一、你的核心定位

你是"功能清单"与"可点击原型"之间的桥梁。调研报告第五章明确指出：竞品在交互设计上普遍存在"重展示、轻教学"的问题，你的工作就是要用交互设计解决这个痛点，让"智承太极"系统以"教学流程"而非"体验流程"为主线，这是本项目与竞品最核心的差异化之一。

你的全部产出，最终要回答评审标准中"流程完整性（10分）"和"工程实用性/可开发商业价值（25分）"这两个维度的要求。

# 二、16周时间线工作清单

## 第1-2周：输入吸收期

**1. **通读调研报告全文，重点研读第二章竞品分析、第三章技术调研、第五章全部分工

- 了解竞品（太极学堂、乐动力太极AI教练、Keep太极课程、太极云传人、非遗武术大模型等）的交互模式与不足

**2. **体验至少4个竞品App/系统，每个使用30分钟以上，记录交互优缺点

- 重点关注：注册流程、课程选择逻辑、动作展示方式、反馈呈现形式、导航结构

**3. **旁听教研员的教师访谈（至少3场）

- 目的：理解真实教学流程和痛点，这是你设计"教学交互闭环"的素材来源

- 记录：教师日常怎么上课？学生常见错误有哪些？考核标准是什么？

**4. **产出《竞品交互体验报告》

## 第3周：架构设计期

**5. **产出信息架构图V1

- 梳理四大模块的层级关系：数字教案库 / AI训练系统 / 战术模拟 / 数字校史馆

- 定义模块间跳转逻辑和全局导航结构

- 参考：高校数字展馆的"时间轴叙事"模式设计数字校史馆浏览路径

**6. **产出教学交互流程图

- 设计完整闭环：学生进入系统 → 选择课程 → 观看3D标准动作 → 跟练并获取AI实时反馈 → 查看量化评分 → 针对性纠正练习

- 参考：VR武当太极系统的"学、练、测、评"一体化模式

**7. **产出用户操作路径图（3条主路径）

- 路径A：学生日常训练路径（从选课到完成一次训练的完整操作）

- 路径B：教师查看学情数据路径（从登录到查看班级/个人训练报告）

- 路径C：评委参观展示路径（点3-5下即可展示系统核心亮点）

**8. **全队评审信息架构

- 和队长、教研员一起过一遍，确保没有遗漏模块、层级逻辑清晰

## 第4-5周：低保真原型期

**9. **Figma搭建全部核心模块的低保真线框图

- 数字教案库：课程列表 → 招式详情 → 3D动作查看器 → 分步教学

- AI训练系统：摄像头校准 → 开始跟练 → 实时骨骼叠加 → 评分结果页

- 战术模拟：对手选择 → 推手对战模拟 → 结果分析（可精简）

- 数字校史馆：时间轴入口 → 展厅漫游 → 互动展品（可精简）

**10. **内审走查：队长、教研员一起走一遍低保真原型，验证教学流程是否合理

## 第6-7周：高保真可点击原型期（核心交付周）

这是你最重要的交付阶段。6-7周原型周期极紧，调研报告将此列为"高风险"，必须聚焦核心模块。

**11. **产出Figma可点击高保真原型，覆盖全部核心模块

- 优先级：数字教案库 > AI训练系统 > 数字校史馆 > 战术模拟

- 战术模拟和校史馆用轻量级框架撑住即可，不要在这里花太多时间

**12. **设计AI反馈的交互呈现方案

- 力量传导线：在画面中怎么展示？用什么颜色/动效？

- 骨节角度标注：标注在画面哪个位置？用浮动面板还是直接叠加？

- 评分呈现：用雷达图、数值、还是等级？综合评分和单项评分怎么展示？

**13. **设计"评委演示路径"

- 评委不是太极大师，原型里要有一条专门的演示路径

- 目标：点3-5下就能展示系统核心亮点，用对比手法让外行看懂设计深度

## 第8-9周：对接完善期

**14. **将三维设计师的3D动作素材嵌入原型

- 在Figma中用视频/GIF占位，展示最终效果

**15. **配合视觉设计师完成UI高保真

- 把你的交互原型交给视觉设计师做视觉美化

- 你负责审核交互逻辑不被视觉改动破坏

- 必须标注每个页面的交互状态：默认态、悬停态、激活态、反馈态

**16. **配合视频导演录屏

- 按"评委演示路径"录一遍原型操作，作为2分钟展示视频的素材

## 第10-13周：文档与展板期

**17. **将交互流程图、信息架构图、用户操作路径图整理进设计说明书

- 交给队长统筹，融入整体文档

**18. **配合视觉设计师制作3DShow云展板的交互逻辑部分

- 评审标准中"文档规范/3DShow云展板"占5分

**19. **参加第13周内审，根据反馈修改原型

## 第14-16周：答辩冲刺期

**20. **准备答辩演示用的原型操作流程

- 确保现场演示流畅不出错，准备备用方案（如录屏备份）

**21. **配合队长完成两次模拟答辩

- 预判评委可能问的交互相关问题并准备回答

# 四、跨角色对接方案

## 4.1 与队长（项目经理）对接

**你从队长那里获取：**

**16****周进度****甘特图****：**明确你每个节点的死线，特别是第3周信息架构评审、第7周原型评审、第13周内审三个关键节点

**答辩****PPT****框架：**了解评委视角，确保你的原型和演示路径与答辩叙事一致

**每周例会议题：**了解全队进度，及时发现与你相关的阻塞点

**你向队长输出：**

**每周进度汇报：**原型完成了哪些模块、遇到什么风险（如"战术模拟模块复杂度超预期，建议砍掉对战细节只保留演示框架"）

**关键评审参与：**第3周信息架构评审、第7周原型评审、第13周内审

**对接节奏：**

每周例会同步进度；第3/7/13周关键评审由队长主持

## 4.2 与教研员（需求分析师）对接 —— 你最重要的输入来源

**你从教研员那里获取：**

**太极拳教学需求功能清单：**你的原型要覆盖的功能列表，这是你设计页面的直接依据

**每招式量化标准数据表：**你设计AI评分展示界面的数据依据（如"野马分鬃"前弓步膝盖角度、重心位置等）

**数字教案库内容架构图：**你设计教案库信息架构的直接输入

**教师访谈记录：**帮助你理解真实教学场景和痛点

**你向教研员输出：**

**交互流程图：**让教研员验证"学生进入 → 选课 → 跟练 → 反馈 → 纠正"这个闭环是否符合真实教学逻辑

**低保真****/****高保真原型：**请教研员走查，验证教学流程的合理性和内容准确性

**对接节奏：**

第1-2周旁听教师访谈 → 第3周拿功能清单开始设计 → 第5周请教研员走查低保真原型 → 第7周请教研员验证高保真原型的教学内容准确性

教研员是你的"内容正确性守门人"，任何涉及太极拳教学流程的交互决策都要过他/她这一关。

## 4.3 与三维设计师对接

**你从三维设计师那里获取：**

**3D****动作资产：**用于嵌入原型的视频/GIF占位，展示3D动作查看器的最终效果

**数字校史馆场景模型：**用于校史馆模块的原型设计参考

**动作可视化素材：**力量传导线、骨节角度标注、重心轨迹 —— 你要决定这些在界面上的呈现位置和交互方式

**你向三维设计师输出：**

**3D****动作****查看器****的素材规格需求：**告诉三维设计师你需要什么角度的渲染（正面、侧面、俯视？）、需要哪些帧的截图用于原型展示

**动作可视化素材的交互呈现规范：**力量传导线用什么颜色/粗细？角度标注浮在画面什么位置？这些由你定义后告诉三维设计师

**对接节奏：**

第4周你出线框图时告诉三维设计师素材规格 → 第8-9周三维素材到位后嵌入原型

## 4.4 与视觉设计师对接 —— 上下游关系

**你从视觉设计师那里获取：**

**视觉风格规范文档：**色彩体系、字体规范、图标库、UI组件库 —— 你据此将低保真升级为高保真

**你向视觉设计师输出：**

**高保真可点击原型（含完整交互逻辑和组件标注）：**视觉设计师在此基础上做视觉美化

**每个页面的交互状态标注：**默认态、悬停态、激活态、反馈态，否则视觉设计师可能只画静态图

**交互走查反馈：**视觉设计师出UI高保真稿时，你做交互走查，确保交互逻辑不被破坏

**对接节奏：**

第6周你出高保真原型初版时与视觉设计师对齐 → 第7周视觉设计师出UI高保真稿时你做交互走查 → 第8-9周联调完善

## 4.5 与视频导演对接

**你从视频导演那里获取：**

**视频分镜头脚本：**你需要知道视频里要展示哪些页面/交互，优先保证这些页面的原型质量

**你向视频导演输出：**

**原型录屏素材：**第8-9周按"评委演示路径"录一遍原型操作，作为视频素材

**特殊角度界面截图：**如果视频需要，你来配合提供

**对接节奏：**

第6周视频导演出分镜脚本后对齐 → 第8-9周录屏交付

# 七、三个核心原则

## 原则一："教学流程"而非"体验流程"

竞品"太极云传人"是体验导向（四大展区），你要以教学闭环为主线。每一个功能设计，都必须回答"它辅助了教学的哪个环节"。这是你和竞品最大的差异化。

## 原则二："外行也能看懂"

评委不是太极大师，你的原型和信息架构要让人3步之内理解系统在干什么。设计一条专门的"评委演示路径"，用对比手法呈现创新点。

## 原则三：做减法

6-7周原型周期极紧。聚焦数字教案库+AI训练系统两个核心模块，战术模拟和校史馆用轻量级框架撑住即可。不要试图做"完美"，要做"能讲清楚故事"的原型。
