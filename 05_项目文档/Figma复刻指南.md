# 第一阶段：准备工作（约 1-2 小时）

## Step 1  截取参考图

在浏览器中打开原型 HTML 文件，逐页截图。共 11 个页面全部截取，包含 hover 状态、按钮按下状态、卡片悬浮状态、Tab 切换状态等关键交互状态也要单独截取。

**截图规格：**1440px 宽度的完整视图，分辨率 1x 和 2x 各一套

**整理方式：**在 Figma 中新建一个 "Reference" 页面，所有截图按页面顺序排列，作为复刻参照

**Tip: ***可用** Chrome **的开发**者工具**截取全页截图，或使用** **GoFullPage** **插件*

## Step 2  建立 Figma 文件结构

新建 Figma 文件，命名为 "智承太极_交互原型_v1"。创建以下页面（Page）：

| **页面名称** | **用途** | **说明** |
|---|---|---|
| Cover | 项目封面 | 项目名称、版本号、日期 |
| Design System | 设计规范 | 颜色变量、字体规范、基础组件库 |
| Hi-Fi Prototype | 高保真页面 | 所有可交互页面放在这里 |
| Flow Diagrams | 流程图 | 信息架构图、用户操作路径图（后续交付用） |

**Tip: ***Figma **中每个** Page **的左上角可以设置颜色标签方便区分*

## Step 3  搭建设计规范（Design System 页）

**3.1 ****颜色变量（****Local Variables****）**

在 Figma 右侧面板 → Local Variables 中创建颜色变量组，把 HTML 中的 CSS 变量逐个对应建好：

| **变量名** | **色值** | **用途** |
|---|---|---|
| bg | #F5F2ED | 宣纸暖白背景 |
| card | #FFFFFF | 卡片背景 |
| accent | #B8312F | 朱砂红，CTA 按钮和激活态 |
| gold | #C4A35A | 哑金色，进度指示和高亮 |
| nav-bg | #0F1419 | 深墨色侧边栏 |
| text | #1A1A1A | 主文本 |
| text-muted | #7A756D | 次要文本/说明文字 |
| border | #D5D0C8 | 边框/分割线 |
| success | #3D8B37 | 成功/已掌握 |
| warning | #D4850A | 警告/学习中 |

**建议：**创建 3 套 Variable Mode —— Default 、Hover 、Active，预定义不同状态的颜色偏移（如 Hover 时 accent 变深、bg 变暖）

**3.2 ****字体规范**

安装 "Noto Serif SC" 字体到系统（从 Google Fonts 下载）。在 Figma 中创建 3 个 Text Style：

| **Style ****名** | **字体** | **字号** | **用途** |
|---|---|---|---|
| Page Title | Noto Serif SC | 24px Bold | 页面主标题，衡线体营造文化厚重感 |
| Card Title | Microsoft YaHei | 16px Semibold | 卡片标题、区块小标题 |
| Body | Microsoft YaHei | 14px Regular | 正文、列表项、描述文字，行高 1.6 |
| Nav Label | Microsoft YaHei | 11px | 侧边栏分组标题，大写字母间距 |
| Caption | Microsoft YaHei | 12px | 卡片元信息、时间戳、次要说明 |

**3.3 ****基础组件库（****Components****）**

以下组件每个都要建立多个变体（Variants）或状态：

| **组件名** | **状态变体** | **关键参数** |
|---|---|---|
| Button/Primary | Default / Hover / Press / Disabled | 朱砂红底白字，8px 圆角，Press 时 Scale 98% |
| Button/Outline | Default / Hover / Press | 透明底描边，Hover 时边框变朱砂红 |
| Card/Base | Default / Hover | 8px 圆角白底，Hover 上移 2px + 阴影加深 |
| Nav Item | Default / Hover / Active | Active 时左侧 3px 朱砂红竖线，背景变深 |
| Tag | 已掌握 / 学习中 / 未开始 | 分别绿色/橙色/灰色背景 |
| Breadcrumb | 单一状态 | 包含链接和当前页两种字体样式 |
| Feedback Item | Good / Warn / Bad | 左侧圆点 + 文字描述，三种颜色 |
| Tab | Default / Active / Hover | 底部 2px 下划线，Active 时变朱砂红 |
| Step Indicator | Done / Current / Future | 圆形步骤节点 + 连接线，Current 带脉冲动效 |

**Tip: ***组件尽量用** Auto Layout**，方便后续调整间距和内容。所有组件放在** Design System **页面的** "Components" **区域*

## Step 4  画侧边栏（只画一次，后续复用）

把侧边栏做成一个 Component，固定在所有页面左侧。关键规格：

**宽度：**220px，全高

**背景：**#0F1419 深墨色

**Logo****：**"智承" 白色 + "太极" 朱砂红，18px Bold

**导航组：**四个分组，每组标题 11px 大写字母间距，颜色 #666

**复用方式：**在每个页面的 Frame 中拖入同一个 Component 实例，切换 Active 状态即可

**Tip: ***侧**边栏底部加用户**头像占位和设置图标，增强产品完成度*

## Step 5  逐页搭建内容区

每个页面的复刻流程统一：

**1. **创建 Frame（1440 × 900），左侧放侧边栏 Component

**2. **右侧内容区用 Auto Layout（垂直方向，gap: 24px，padding: 32px 40px）

**3. **参照 Reference 页面的截图，用前面建好的组件拼装内容

**4. **所有颜色必须引用 Local Variables，不要硬编码

**5. **文字必须引用 Text Styles，不要手动设字号

**各页面关键搭建要点**

**首页总****览****：**

- Welcome Banner：标题 + 连续训练天数 + 本周目标进度

- 3 个统计卡片：用 Arc 工具画 SVG 圆环进度，Stroke 设为对应颜色

- 2 个快速操作卡片：继续学习 + 开始训练

- 教师反馈提示框：左侧 3px 朱砂红竖线，淡粉背景

- 太极水印装饰：用钢笔工具画太极图标（2 个半圆 + 2 个小圆），7% 透明度

**课程列表：**

- 搜索栏 + 2 个筛选下拉框（套路 / 难度）

- 2 列卡片网格：每张卡片含招式名称 + 难度标签 + 状态标签 + 关键帧占位

- 关键帧用 SVG 线条人形剪影替代，每个招式手臂姿势不同

**3D ****动作查看器：**

- 深色渐变矩形模拟 3D 视口（#1a1a2e → #0f3460）

- 中间放简化人形剪影（钢笔工具画轮廓，白色半透明）

- 右上角 3 个圆形控制按钮（旋转/重置/全屏）

- 底部播放控制条：上一帧、播放、下一帧、进入 AI 训练

**评分结果页（重点页面）：**

- 3 个统计卡片：综合得分圆环用 Arc 工具 + 整体评价 + 建议方向

- SVG 雷达图：用 Polygon 工具画正五边形（参考线）+ 填充五边形（数据面）

- 5 个维度：力量传导、节奏匹配、关节活动、步型规范、身体中正

- 针对性纠正建议卡片 + “前往分步教学”按钮

# 第三阶段：添加 Figma 交互（约 3-5 小时）

## Step 6  设置 Prototype 连接

在 Figma 右下角 Prototype 面板中，逐页添加交互链接。以下是完整的交互映射表：

| **触发元素** | **动作** | **目标页面****/****状态** |
|---|---|---|
| 侧边栏 Nav Item | On Click → Navigate To | 对应页面 Frame |
| 面包屑链接 | On Click → Navigate To | 上级页面 |
| 课程卡片 | On Click → Navigate To | 招式详情页 |
| 招式详情 Tab | On Click → Change To | 同页面其他 Tab 状态 |
| "进入 3D 查看"按钮 | On Click → Navigate To | 3D 动作查看器页面 |
| "进入 AI 训练"按钮 | On Click → Navigate To | AI 校准页面 |
| 分步教学 “下一步” | On Click → Change To | 下一步骤状态 |
| "前往分步教学"按钮 | On Click → Navigate To | 分步教学页面 |
| "完成并查看评分” | On Click → Navigate To | 评分结果页 |
| 首页“继续学习” | On Click → Navigate To | 课程列表页 |
| 首页“开始训练” | On Click → Navigate To | AI 校准页 |

## Step 7  添加过渡动效

Figma Prototype 设置如下：

| **交互场景** | **动****效类型** | **参数** |
|---|---|---|
| 页面跳转 | Smart Animate | 200ms, Ease Out |
| Tab 切换 | Instant / Dissolve | 150ms |
| 按钮点击 | While Pressing 状态 | Scale 98% |
| 卡片悬浮 | While Hovering 状态 | 已在 Component 中定义 |

**Tip: ***Smart Animate **需要两个** Frame **中的元素命名一致才能正常工作，确保**侧边栏在**所有页面中使用同一个** Component **实例*

## Step 8  设计“评委演示路径”

这是竞赛答辩的核心交互流程，目标是 3-5 步展示系统核心亮点。在 Prototype 面板中单独建一个 Flow，命名为“评委演示路径”：

| **步骤** | **操作** | **展示要点** |
|---|---|---|
| 1 | 查看首页总览 | 展示整体数据看板和快速入口 |
| 2 | 点击“继续学习” | 进入课程列表，展示教案库丰富度和状态跟踪 |
| 3 | 点击“单鞔”卡片 | 进入招式详情，展示教学深度（动作要点 + 量化标准） |
| 4 | 点击“标准动作 3D” Tab | 进入 3D 查看器，展示技术亮点（可视化图层切换） |
| 5 | 点击“进入 AI 训练” | 展示 AI 评分闭环：跟练 → 反馈 → 评分 → 纠正 |

# 第五阶段：交付物输出（约 2-3 小时）

## Step 9  导出给开发/团队

**1. ****切图导出****：**选中所有 Frame → Export → PNG @1x 和 @2x

**2. ****属性复制：**使用 Figma Dev Mode 或 Copy/Paste as → Copy properties 给开发参考间距和颜色

**3. ****分享设计规范：**把 Design System 页单独分享给视觉设计师

**4. ****流程图导出：**把 Flow Diagrams 页导出为 PDF，附入设计说明书

## Step 10  录制演示视频

**1. **用 Figma 自带的 Prototype 录屏功能，按“评委演示路径”走一遍

**2. **导出 MP4，作为 2 分钟展示视频的素材

**3. **如需精剪，可用 Premiere 或 DaVinci 后期加字幕和转场
