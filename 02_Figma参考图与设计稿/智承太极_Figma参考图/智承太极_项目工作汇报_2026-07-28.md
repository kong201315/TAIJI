# 三、AI协作开发模式

本项目采用了创新的双AI协作开发模式，由两个AI分身分工配合完成开发工作：

| **角色** | **名称** | **平台** | **定位** | **负责领域** |
|---|---|---|---|---|
| 🧠 大脑 | 小朱 | Claude Code | 裁决者 + 代码引擎 | 架构决策、代码编写、Bug修复、任务编排、最终审核 |
| 🦊 感官 | 小夏 | OpenClaw Agent | 特种兵 + 感官系统 | 浏览器操作、截图审查、DOM调试、字体/素材管理、主动发现问题 |

**协作流程：**

① 小朱进行代码编写和修改 → ② 小夏在浏览器中打开页面截图审查 → ③ 小夏发现问题反馈 → ④ 小朱修复 → ⑤ 小夏再次截图确认，形成闭环。

**该模式的核心优势在于：**

• 代码编辑与视觉验证分离，两个角色各司其职

• 小夏通过浏览器 CDP 协议（Edge DevTools Protocol 9222端口）进行精确的 DOM 调试

• 视觉审查可发现纯代码审查无法察觉的布局和渲染问题

• 当天共完成 4 轮截图审查（第一轮4张 + 第二轮2张确认），所有问题均已闭环
