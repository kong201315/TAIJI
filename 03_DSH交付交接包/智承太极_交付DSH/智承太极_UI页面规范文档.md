# 智承太极数字教学系统 UI 页面规范文档

> 适用：Figma页面复刻 / AI界面生成提示词

## 一、全局通用基础规范（所有页面统一，优先加载）

### 1. 布局结构
全站统一**左右固定分栏布局**
- 左侧：固定宽度侧边导航栏（永久悬浮）
- 右侧：自适应主内容容器

### 2. 全局色彩规范
| 用途 | 色值 | 备注 |
| ---- | ---- | ---- |
| 主内容页面背景 | `#F8F6F0` | 米杏底色 |
| 左侧侧边栏背景 | `#1E2229` | 深炭黑色 |
| 通用卡片底色 | `#FFFFFF` | 白色卡片 |
| 主强调色（按钮、选中、进度条） | `#C83636` | 暗红色（太极主题主色） |
| 一级标题文字 | `#222222` | 深黑灰 |
| 二级正文文字 | `#666666` | 中性灰 |
| 侧边栏一级菜单文字 | `#EAEAEA` | 浅灰白 |
| 侧边栏二级菜单文字 | `#C2C2C2` | 浅灰色 |
| 招式编号色块 | `#EAE3DA` | 浅米色 |
| 预览容器深色背景 | `#20262F` | 视频/3D预览框底色 |

#### 状态标签配色
| 标签状态 | 背景色 | 文字色 |
| ---- | ---- | ---- |
| 已掌握 | `#E6F3E8` | `#2F8543` |
| 学习中 | `#F8F1D9` | `#A47C23` |
| 未开始 | `#EEEEEE` | `#777777` |

### 3. 圆角规范
- 大模块卡片、预览窗口：`8px`
- 导航标签、按钮：`6px`
- 状态小标签：`6px`

### 4. 通用风格前缀（所有提示词开头固定）
B端网页后台UI，新中式极简轻量化教学平台界面；布局规整、留白舒适、低饱和度柔和配色；使用Auto Layout自动布局，组件化设计；仅绘制网页UI界面，不要3D渲染效果图，适合Figma原型搭建；无多余花哨装饰，商务阅读友好字体。

### 5. 左侧侧边导航【全站共用组件】
顶部标题：**智承太极｜数字教学系统**
菜单层级：
1. 首页总览

   - 课程列表
   - 招式详情
3. 3D动作查看器
   - 分步教学

   - 摄像头校准

## 附加：Figma搭建实操建议
1. 先建立样式库（颜色/圆角/文字样式），复制文档内色值一键创建；
2. 左侧导航栏制作主组件，所有页面直接实例复用；
3. 招式卡片、状态标签、按钮制作组件变体；
4. 页面间距、内边距统一数值，全程使用自动布局，方便后期迭代适配。
