## 3. 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | **原生 HTML/CSS/JS**（单文件 `index.html`） | 无框架、无构建、无 npm 依赖 |
| 后端 | **Node.js**（`server.js`） | 仅用 `http/fs/path` 内置模块，零第三方依赖 |
| 数据 | `data.json` | JSON 文件持久化，服务端读写 |
| 启动 | `node server.js` | → `http://localhost:8080` |

**重要**：不能直接双击 `index.html`（前端通过 `/api/*` 取数），必须经 `node server.js` 起服务。

---

## 4. 启动方式

```bash
cd 项目源码
node server.js
# → http://localhost:8080
```

- 支持 `PORT` 环境变量换端口（8080 曾与 make-ppt 的 agentgo 冲突，必要时 `PORT=8081 node server.js`）。
- `data.json` 不存在时自动创建并写入默认数据。

## 5. API 清单（后端 `server.js`）

| 方法 | 路径 | 作用 |
|------|------|------|
| GET  | `/api/user` | 取当前用户（姓名/班级） |
| POST | `/api/user` | 更新用户，body `{name, klass}` |
| GET  | `/api/dashboard` | 取首页统计（分数/掌握数/本周进度/境界/快捷建议/教师反馈） |
| GET  | `/api/records` | 取训练记录（最多 7 条） |
| GET  | `/api/forms` | 取已掌握招式映射 |
| POST | `/api/training` | 提交一次训练，body `{form, seconds}`；完成即计分并返回最新状态 |

**训练计分规则（当前 A 方案，无 AI 判别）：**
- 每式均分 **6.25 分**，16 式满分 **100**
- **不重复加分**：已掌握招式再练 +0
- **不扣分**；**从零累积**，后台无自动噪声，分数完全由 `/api/training` 驱动
- 6 级境界：未开始 / 入门 / 初学 / 小成 / 大成 / 圆满
- 前端评分报告页按 `N` 进下一式

**架构要点**：前端 `DataAPI` 是可替换数据源层，当前接真后端 `/api/*`——换 AI 评分时只改后端，界面不用动。
