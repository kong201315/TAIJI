### 升级内容明细

1. **后端 REST API（5 个端点）**
   - `/api/user`（GET/POST）— 用户信息读写
   - `/api/dashboard`（GET）— 首页统计/环形/本周目标数据
   - `/api/records`（GET）— 训练记录
   - `/api/forms`（GET）— 招式掌握状态
   - `/api/training`（POST）— 训练提交与评分

2. **登录层**：姓名/班级 → localStorage + POST 后端持久化，侧边栏/Banner 实时换名，设置里可切换账号

3. **训练闭环**：完成训练 → 后端评分 → 加分 → 实时刷新
   - 每式均分 **6.25 分**，16 式满分 **100**
   - **不重复加分**（已掌握招式再练 +0）、**不扣分**（当前 A 方案简化，无 AI 判别）
   - **从零累积**（score 完全由训练驱动，后台无噪声）
   - **6 级境界**：未开始 / 入门 / 初学 / 小成 / 大成 / 圆满

4. **全页面联动**：首页 Stat/环形进度/本周目标、招式列表（已掌握/未开始）、评分报告（等级 + `N` 快捷键进下一式）、训练记录页——全部由后端数据驱动

5. **前端架构**：`DataAPI` 数据源可替换（当前接真后端 `/api/*`）
