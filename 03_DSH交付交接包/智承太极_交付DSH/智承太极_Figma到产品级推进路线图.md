## 三、Figma 推进路线（交互设计师主线）

### 第 1 阶段：核心页面铺开（当前）
按优先级在 Figma 中补齐高保真页面：

1. ✅ 首页 Dashboard
2. ✅ 课程列表
3. ⬜ 课程概览（杨氏十六式）
4. ⬜ 招式详情（以“起势”为例）
5. ⬜ 3D 动作查看器
6. ⬜ 分步教学
7. ⬜ AI 训练：摄像头校准 / 实时跟练 / 评分结果 / 训练记录
8. ⬜ 数字校史馆：时间轴入口
9. ⬜ 战术模拟：推手对战（轻量版）
10. ⬜ 设置弹窗

### 第 2 阶段：可点击化
- 页面之间建立跳转（原型连线）
- 每个按钮标注交互状态：默认 / 悬停 / 激活 / 反馈
- 重点闭环：首页 → 课程列表 → 招式详情 → 3D 查看 → 分步教学 → 实时跟练 → 评分结果

### 第 3 阶段：AI 反馈交互呈现
- 力量传导线：颜色 / 粗细 / 出现位置
- 骨节角度标注：叠加方式 / 浮动面板
- 评分展示：雷达图 / 数值 / 等级
- 教师反馈与纠正建议

## 四、产品级落地路线（开发主线）

### 第 1 步：Web 视觉对齐 Figma
- 把现有 Web 应用逐页对齐 Figma 高保真
- 统一颜色、字体、圆角、阴影、间距
- 确保“Figma 能点的，Web 也能点”

### 第 2 步：真实数据接入
- 用户登录数据
- 课程/招式/训练记录/评分数据
- 教师反馈数据

### 第 3 步：AI 评分（B 方案）
- 摄像头姿态识别
- 动作匹配与量化评分
- 实时反馈（力量传导线、骨节角度）
- 替换当前 `/api/training` 的简单给分逻辑

### 第 4 步：3D 素材嵌入
- 先用 16 式视频/GIF 占位
- 三维设计师素材到位后替换
- 3D 查看器支持视角切换、速度控制、骨骼线开关

### 第 5 步：演示路径与录屏
- 设计“评委 3-5 步演示路径”
- 按路径录制 2 分钟演示视频
- 准备备用录屏
